Правила без сети

Сохранённые публичные карточки этого браузера. Снимки не обновляются автоматически; личные переводы и данные аккаунта сюда не попадают. Очистка данных браузера удалит копии.

Выберите карточку. Чтобы добавить правила, откройте их в приложении при подключении к интернету и нажмите «Сохранить для чтения без сети».

# Android и iOS

Обе мобильные версии используют ваш сервер D&D Companion и его аккаунты. Разместите актуальный сервер, затем введите его HTTPS-адрес в приложении. Вход нужен для личных данных, справочники доступны гостю. База не вшита в APK или iOS-проект. Обновление серверных разделов не требует пересборки мобильного клиента, если протокол оболочки не меняется.

| | Android | iPhone / iPad |
|---|---|---|
| Проект | Java, Android WebView | Swift, UIKit, WKWebView |
| Минимальная ОС | Android 8.0 | iOS 15 |
| Результат этой сборки | APK 0.2.0-debug, подпись проверена | Xcode-проект и исходники; Swift не скомпилирован на Windows |
| Файлы | Выбор через систему, сохранение в выбранную папку | Выбор через WebKit, сохранение через «Поделиться → Файлы» |
| Печать | Системная печать / PDF | Системное окно печати |
| Правила без сети | Подготовленный Service Worker и IndexedDB выбранного сервера | Приватное native-хранилище с отдельным читателем, без зависимости от Service Worker |
| Подпись выпуска | Нужен ваш Android keystore | Нужны Xcode, Team и provisioning profile |

Android APK предназначен для проверки и установлен под отдельным debug-ID. В нём не сохранены адрес сервера, пароли или чужие персонажи. При отсутствии хостинга можно проверить Android по USB через `adb reverse tcp:3000 tcp:3000` и адрес `http://127.0.0.1:3000`. Для обычного использования на телефонах требуется размещённый HTTPS-сервер.

Инструкции: [Android](../android/README.md), [iOS](../ios/README.md). Подготовлены исходники для iPhone и iPad, но установочный IPA и публикация в магазинах не выполнялись. На Windows нет Xcode/iOS SDK и Apple-подписи; проверка Swift, симулятора и устройства остаётся обязательным шагом на Mac.

## Результаты проверки

- Android: JVM-тесты 3/3, `lintDebug`, `assembleDebug` успешны. Lint: 0 ошибок, 4 прежних предупреждения. APK проверен `apksigner`, v2-подпись корректна.
- Веб и мосты: 148 автотестов, TypeScript, ESLint изменённых файлов и производственная сборка прошли. Проверены перехват экспорта отсоединённых ссылок, отказ при чужом origin, вызов native-печати и подтверждение записи автономной карточки.
- iOS: XML plist, privacy manifest и общая схема Xcode проверены на синтаксическую корректность. Включены тесты URL-политики и `build.sh` для Mac. Это не проверка компиляции Swift или работоспособности UI.
- На физических устройствах обе платформы в этой сессии не запускались. WebView и WKWebView необходимо проверить с реальным сервером, файлами, принтером/PDF, авиарежимом, сменой сервера и авторизацией.

Оболочки не предоставляют автоматическую синхронизацию правок без интернета. Локально сохраняются только явно выбранные публичные правила; исходные ограничения полноты справочников остаются видимыми.

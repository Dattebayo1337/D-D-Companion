# Черты обеих Книг игрока

Добавлены 86 самостоятельных русских сводок по карточкам DnD.su: 37 для 2014 и 49 для 2024. Вместе с существующими пакетами покрыты все 42 черты PHB 2014 и 75 черт PHB 2024. В редакции 2014 также сохранены четыре ранее добавленные черты из дополнений: всего 46.

У каждой новой записи есть ссылка на конкретную карточку, требования, тип черты, предел повышения характеристик и краткое объяснение механики. Редакции имеют разные идентификаторы и описания. Полные переводы книг и изображения не включены. Эти записи имеют статус MetadataOnly и не объявлены материалом SRD или CC BY. Выбор черты в персонаже не означает автоматическое применение всех её эффектов.

Источники: https://dnd.su/feats/ и https://next.dnd.su/feats/; конкретные ссылки сохранены в каждой записи. Сверка каталога: 24 сентября 2026. Остальные черты дополнений на сайте пока покрыты частично.

Исходные сводки: data/phb/feats-curated.json. Сборка: npm run data:feats:build. Импорт: npm run data:feats; также включён в npm run data:srd. Повторный импорт не создаёт дубликаты. Проверки сравнивают объединение пакетов с полными списками PHB в сохранённом каталоге, проверяют различия редакций, локализацию и повторный импорт.

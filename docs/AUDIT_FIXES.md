# Исправления после аудита — 2026-10-02

## Сравнение редакций — пункты 57–59

В карточках заклинаний, существ и справочников появилась кнопка «Сравнить редакции». Выберите вторую запись: две колонки показывают сохранённые поля, различия выделены, есть переключатель «Только различия». Окно расширяется для чтения рядом; на узком экране колонки располагаются друг под другом.

Сначала используются ContentRelation в обоих направлениях. Совпадения названий и псевдонимов обозначены как предположительные; для подклассов дополнительно проверяется соответствие родительских классов. Неутверждённые записи не выдаются, Homebrew не связывается автоматически. Различие перевода не объявляется изменением механики. Сравнение всегда использует исходные тексты, без личных переопределений.

## Фильтры — пункты 18 и 22

Заклинания: добавлены класс, подкласс, время, тип урона, спасбросок, атака, вид дальности и минимальная дальность. Бестиарий: окружение и минимальная скорость выбранного движения. Чувства и применение магии учитывают русские поля, а не только английский исходник. Несовместимые фильтры разных типов записей не игнорируются. Фильтрация выполняется до подсчёта количества и пагинации.

Класс и подкласс задаются полным названием, расстояния — в футах. Результаты зависят от заполненных полей: сведения только в прозе не становятся автоматически структурированными данными. Это ограничение обозначено в интерфейсе.

## Личные переводы — пункт 92

Кнопка «Мой перевод / пояснение» позволяет аккаунту изменить название или основное описание в своём представлении карточки. Есть возврат к библиотечному тексту, защита от перезаписи варианта из другого окна и предупреждение при выходе с несохранённым текстом. В общей библиотеке, поиске, отдельных умениях и игровых числах изменений нет.

Данные изолированы по аккаунту. Гостям редактор недоступен, справочники и сравнение остаются открытыми. После изменения исходного поля старый пользовательский вариант сохраняется для сверки, но больше не подменяет актуальную версию.

## Структурированные поля заклинаний

По уже сохранённым лицензированным SRD-текстам проверены восемь заклинаний в каждой редакции: Огненный шар, Кислотные брызги, Магическая стрела, Лечение ран, Целебное слово, Огненный снаряд, Луч холода, Шоковый захват. Добавлены соответствующие спасброски, типы атак, урон, лечение и усиление. У Магической стрелы не добавлен бросок атаки; величина урона обозначена на одну стрелу. Лечение 2014/2024 различается. Основные описания не переписаны.

Результаты хранятся в `data/srd/spell-fields-reviewed.json`; сборщик SRD воспроизводит их с contentVersion 2. Обычный импорт по-прежнему запрещает изменение официальной записи. Для существующей установки предусмотрена отдельная обслуживающая миграция:

```powershell
node --env-file=.env --import ./scripts/register.mjs scripts/migrate-reviewed-spell-fields.ts
```

Сначала сделайте резервную копию БД. Миграция принимает только точные исходные снимки этих 16 записей, отклоняет любые сторонние изменения, выполняется одной транзакцией и сохраняет ContentRevision. Повторный запуск пропускает уже обновлённые записи. Новая установка импортирует обновлённые JSON обычным способом. На текущей установке перед изменением создана `backups/before-spell-fields-2026-10-02.db`.

## Оставшиеся замечания

Эта поставка не закрывает все 120 пунктов ТЗ. Сохраняются 403 обзора MetadataOnly и 94 подкласса без дополнительных подробностей; полный каталог и все структурированные поля ещё не заполнены. Не реализованы универсальная система эффектов и единый backup/restore всех данных вместе с настройками браузера. Полная автоматизация способностей и масштабные испытания PostgreSQL также остаются отдельными задачами. Android по согласованному объёму остаётся онлайн-клиентом.

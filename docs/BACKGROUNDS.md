# Предыстории обеих «Книг игрока»

Состав после установки дополнения:

| Редакция | Основные | Варианты | Всего |
| -------- | -------: | -------: | ----: |
| 2014     |       13 |        5 |    18 |
| 2024     |       16 |        0 |    16 |

Для 2014 добавлены Шарлатан, Преступник, Артист, Народный герой, Гильдейский ремесленник, Отшельник, Благородный, Чужеземец, Мудрец, Моряк, Солдат и Беспризорник. Варианты: Шпион, Гладиатор, Гильдейский торговец, Рыцарь и Пират. Послушник уже доступен в SRD.

Для 2024 добавлены Ремесленник, Шарлатан, Артист, Фермер, Стражник, Проводник, Отшельник, Торговец, Благородный, Моряк, Писец и Скиталец. Послушник, Преступник, Мудрец и Солдат остаются существующими записями SRD. Добавлены сводки шести недостающих черт происхождения: Ремесленник, Целитель, Везунчик, Музыкант, Драчун и Крепкий.

## Формат карточек

Новые записи — самостоятельные краткие русские сводки механики: навыки, инструменты, языки для 2014, характеристики и черта для 2024, начальное снаряжение и особенность. Это не полные тексты книг: иллюстрации, повествовательные описания и таблицы личностных черт не копировались. Новые записи имеют `MetadataOnly` / «Справочная сводка», отдельный источник и ссылку на использованный материал. Им не приписана лицензия SRD. Предыдущие UUID и полные записи SRD не менялись, персонажи сохраняют свои ссылки.

Варианты 2014 — отдельные выбираемые карточки с указанием базовой предыстории. Не смешиваются с редакцией 2024. Дополнительные книги в это обновление не входят.

## Источники и воспроизводимость

- Состав книг: [официальный каталог D&D Beyond](https://www.dndbeyond.com/backgrounds), [обзор предысторий 2024](https://www.dndbeyond.com/posts/1785-the-backgrounds-and-origin-feats-in-the-2024).
- Механика 2024: отдельные страницы опубликованного Roll20 Compendium, например [Фермер](https://roll20.net/compendium/dnd5e/Backgrounds:Farmer?expansion=32231); для [Проводника](https://wastedwizardgames.com/dnd/2024/backgrounds/guide/) использована сводка WWG. Точный URL записан в `source` каждой карточки.
- Механика 2014: открытые страницы D&D Beyond для Преступника/Шпиона, Мудреца и Солдата; справочные страницы DND 5th Edition Wiki для остальных. Используются краткие изложения фактов, а не исходные тексты страниц.
- Проверено 17 сентября 2026. Сборщик не обращается к сети: исходные сводки и ссылки записаны в `scripts/build-backgrounds.ts`.

```sh
pnpm data:backgrounds:build
pnpm data:backgrounds
```

Обычный `pnpm data:srd` теперь также импортирует это дополнение после SRD. Повторный импорт идемпотентен. Пакеты: `data/phb/backgrounds-2014.json` (17 записей), `data/phb/backgrounds-2024.json` (12 предысторий + 6 черт). Суммарно добавлены 35 записей; 29 из них — предыстории.

Тесты сверяют полный поимённый состав, отсутствие дублей, редакции, повторный импорт, поиск и создание персонажа с новой предысторией. Предыстория другой редакции отклоняется.

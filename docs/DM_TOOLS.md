# Инструменты мастера

Откройте «Инструменты мастера» → «Случайная добыча» или «Калькулятор боя». Общий переключатель 2014 / 2024 определяет редакцию справочников и правил. Черновики редакций сохраняются отдельно в браузере.

## Калькулятор боя

Задайте количество и уровни персонажей; для смешанной группы добавьте строки. Найдите противников в бестиарии по имени, показателю опасности, типу или книге и добавьте нужное количество. Название открывает полную карточку.

Для 2014 суммируются пороги персонажей, а опыт противников умножается на коэффициент количества существ с поправкой на размер группы. Флажок позволяет исключить слабое существо из подсчёта множителя; его опыт остаётся в сумме. Скорректированный опыт определяет сложность, исходный — награду.

Для 2024 суммируются бюджеты персонажей без множителя количества противников. Результат показывает минимальный бюджет, в который помещается бой: низкий, умеренный или высокий; превышение высокого бюджета отмечается отдельно. Выбор целевой сложности показывает остаток или превышение бюджета.

Оценка не моделирует тактику, местность, ресурсы группы и взаимодействие способностей. Состав боя можно скачать текстом. Черновик хранит снимок параметров существ; после обновления справочника добавьте их заново для получения новых значений.

Источники числовых правил: [Basic Rules 2014](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/building-combat-encounters), [Basic Rules 2024](https://www.dndbeyond.com/sources/dnd/br-2024/dms-toolbox). Таблица 2024 также доступна в используемом проектом SRD 5.2.

## Случайная добыча

Выберите уровень, личную добычу или клад, достаток, число магических предметов, редкость и книгу. Предметы выбираются из утверждённых записей справочника текущей редакции без повторов в одном результате. Записи с неоднозначной редкостью исключаются; интерфейс показывает их количество. Если подходящих предметов недостаточно, измените фильтры или количество.

Монеты и ценности генерируются по **авторской таблице приложения**, а не официальным таблицам сокровищ. Стоимость монет: 2к6 × масштаб уровня (5 / 25 / 100 / 500 зм для уровней 1–4 / 5–10 / 11–16 / 17–20), с коэффициентом достатка 0,5 / 1 / 2 и коэффициентом клада 10. Клад содержит 1к4 ценности; личная добыча — одну при результате 5–6 на к6. В автоматическом режиме верхняя редкость по этим диапазонам — необычная, редкая, очень редкая и легендарная.

Необязательное зерно позволяет повторить бросок при одинаковых настройках и составе каталога. История сохраняет последние пять результатов каждой редакции. Названия предметов открывают карточки; результат можно скопировать или скачать текстом. Общая стоимость учитывает монеты и ценности, но не магические предметы. В инвентарь персонажа добыча автоматически не добавляется.

## Хранение

Настройки, история добычи и состав боя находятся в localStorage браузера. Они не входят в экспорт библиотеки и резервную копию SQLite. Очистка данных браузера удаляет черновики; для сохранения результата используйте текстовый экспорт. Миграция базы данных не требуется.

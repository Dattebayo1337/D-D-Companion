# Набор заклинаний SRD

Включены все 319 записей каталога SRD 5.1 и все 339 записей каталога SRD 5.2.1 из корпуса OmnisGM. Это 658 записей двух редакций; одинаковые заклинания разных редакций считаются отдельно. Четыре ранее существовавших учебных заклинания Homebrew сохранены отдельно. Бестиарий расширен до 647 записей SRD; справочники содержат 1214 записей. Подробнее — PHASE2.md.

Источник: https://github.com/OmnisGM-App/OmnisGM-Rules, commit `9d31cc106d780a62cef82cf4e2caa9f9d2dcccb5`. Официальный SRD: https://www.dndbeyond.com/srd. Исходники английского текста, русского перевода, глоссариев и лицензий хранятся в `data/raw/`. `srd-sources.json` фиксирует URL, Git blob SHA, SHA-256, размер и время загрузки каждого файла. Сборщик проверяет SHA-256 до обработки, работает без сети.

## Преобразование

`scripts/build-srd.ts` строит два JSON-пакета. Русские записи сопоставляются с английскими по оригинальному названию, явно указанному автором в русском заголовке. Состав проверяется по обоим глоссариям, включая уровни 0–9. Между редакциями не создаются автоматически связи эквивалентности. UUID детерминированы из пространства имён проекта, редакции и ключа записи; названия не служат первичными ключами базы.

Сохраняются полные русские и английские описания, включая усиление на высоких уровнях, таблицы и вложенные характеристики призываемых существ. Классы, школа и уровень берутся из английского глоссария; время, компоненты, дистанция, длительность, концентрация и ритуал — из заголовков записи. Стоимость отражает явно указанную цену в золотых; для сложных требований материалов точным источником остаётся полный текст компонента. Урон, лечение, цели, спасброски и состояния находятся в полном описании; сложная механика не угадывается регулярными выражениями для дополнительных структурированных полей. Это справочник, не расчётный движок заклинаний.

Дистанции «На себя», «Касание», «В пределах видимости», «Особая» и «Неограниченная» имеют отдельный тип и русский текст. Для обычных числовых дистанций сохраняются футы (мили переводятся в футы), метрическое отображение вычисляется отдельно. Для «На себя» сохраняется исходное уточнение области. Допустимый числовой предел расширен до 10 миллионов футов для дальних заклинаний.

Изменения исходников при сборке (сами файлы raw неизменны):
- Поддержано ошибочное `Component` вместо `Components` у Contagion 2014.
- Убраны четыре дублирующих английских названия из русских заголовков вложенных характеристик: Otherworldly Steed, Giant Insect, Animated Object, Draconic Spirit.
- `Table:` заменено на «Таблица:» у Confusion и Teleport 2024.
- Ссылки Markdown превращаются в текст; таблицы и выделения отображаются безопасными React-элементами без исполнения HTML.

## Перевод и проверка

Используется опубликованный перевод OmnisGM по CC BY 4.0. `Approved` означает допуск этого опубликованного набора к показу после структурной и языковой проверки; это не заявление о независимой построчной человеческой вычитке всех 658 переводов. Выполнена выборочная проверка различий Cure Wounds и Acid Splash, дистанций, материальных компонентов, концентрации, ритуалов и таблиц. Проверки не устанавливают безошибочность всех формулировок стороннего перевода.

Команды:

```sh
pnpm data:srd:build
pnpm data:srd
pnpm validate:ru
pnpm test
```

Импорт каждой редакции атомарен. Повторный запуск пропускает совпадающие записи. Официальные записи защищены от перезаписи; изменение текста в будущих версиях требует нового UUID и явного управления связями/версиями. Исходные уведомления авторства и тексты лицензий включены в архив проекта.

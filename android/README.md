# D&D Companion для Android — онлайн-клиент

Нативный Android-проект на Java/WebView. Минимум Android 8.0 (API 26), compile/target SDK 35. Аккаунты, база, карты и лобби работают на вашем сервере; сайт и мобильное приложение используют одну серверную версию. Адрес можно изменить без пересборки APK.

## Подключение после размещения

Готовая тестовая сборка: `dnd-companion-android-debug.apk` рядом с архивом исходников. Перенесите APK на телефон, откройте его и при запросе Android разрешите установку из используемого файлового менеджера. После установки запустите **D&D Companion · тест**. До размещения сервера можно проверить подключение по USB по инструкции ниже; произвольный адрес примера работать не будет.

1. Разместите актуальный сервер по инструкции `../docs/LOBBY.md` и `../docs/ACCOUNTS.md`. Настройте HTTPS и `APP_ORIGIN=https://ваш-домен`.
2. Откройте приложение и введите только адрес сервера, например `https://game.example.ru` — без пути `/login` или `/play`.
3. Клиент проверяет `GET /api/mobile/status`. Ответ: `{"application":"dnd-companion","protocol":1}`.
4. Справочники открываются без входа. Войдите в обычный аккаунт для личных данных. Не вводите ключ администратора в адрес сервера.

Смена адреса: нажмите название сервера в верхней панели или **⋮ → Адрес сервера**. При смене сервера удаляются локальные cookies, веб-хранилище и кэш предыдущего подключения. Пользовательские данные на сервере остаются. Вводите адрес сервера, которому доверяете.

## Что поддерживает клиент

- Сессия аккаунта между запусками, общая библиотека и существующие личные разделы.
- Загрузка PNG/JSON через системный выбор файлов; приложению не нужен общий доступ к памяти телефона.
- Скачивание приватных PNG с cookies аккаунта, а также SVG/JSON из браузерных экспортов. Системное окно предлагает папку сохранения. Поддерживается текстовый MIME экспорта заметок и резервных копий.
- Кнопка «Назад» сначала закрывает карточку/меню, затем возвращает на главную или предыдущую веб-страницу.
- Системная печать / PDF из предпросмотра листа и меню приложения.
- Экран ошибки подключения, повтор загрузки, смена сервера; поддержка поворота экрана.
- Внешние HTTP(S)-ссылки открываются в браузере. Native-мост сохранения принимает сообщения только от главного фрейма настроенного сервера.

Для серверных данных нужен интернет. Выбранные публичные справочники можно заранее сохранить кнопкой «Сохранить для чтения без сети» и открыть через меню «Читать без сети». Нужен актуальный сервер и поддерживающий Service Worker Android System WebView; используется HTTPS либо localhost при USB-тестировании. Автономное редактирование и фоновая синхронизация не добавлены. Обновляйте Android System WebView; экспорт Blob требует поддержки WebMessageListener. Предел скачивания — 64 МБ с сервера и 16 МБ для SVG/JSON Blob.

## Сборка в Android Studio

1. Установите Android Studio и JDK 17. В SDK Manager установите **Android SDK Platform 35** и **Build-Tools 35.0.0**; примите лицензию Android SDK самостоятельно.
2. Откройте каталог `android` как проект. Дождитесь Gradle Sync.
3. Выполните **Build → Build APK(s)** для тестовой сборки либо запустите приложение на подключённом устройстве.

Из PowerShell:

```powershell
./build.ps1 -SdkRoot 'C:/Users/you/AppData/Local/Android/Sdk' -JavaHome 'C:/Program Files/Java/jdk-17'
```

Скрипт запускает JVM-тесты, Android Lint и `assembleDebug`. Результат: `app/build/outputs/apk/debug/app-debug.apk`. Gradle Wrapper 8.11.1 и AGP 8.9.2 закреплены; для первого запуска нужен доступ к официальным репозиториям Gradle, Google Maven и Maven Central. SHA-256 дистрибутива Gradle закреплён в wrapper properties.

Для выпуска используйте **Generate Signed Bundle / APK** в Android Studio. Создайте и сохраните свой ключ подписи вне репозитория. Текущий package ID: `app.dndcompanion.mobile`, у debug-сборки добавлен `.debug`. Перед первым публичным выпуском утвердите постоянный ID и проверьте актуальные требования магазина к target SDK. Подпись выпуска, публикация и аккаунт магазина не создаются автоматически.

## Проверка до хостинга

Только debug-сборка разрешает HTTP для локальных IP. Сертификат с ошибкой не принимается ни в одной сборке.

- Эмулятор: `http://10.0.2.2:3000`.
- Телефон по USB: включите отладку USB, выполните `adb reverse tcp:3000 tcp:3000`, укажите `http://127.0.0.1:3000`. Сервер может оставаться привязанным к 127.0.0.1 на компьютере.
- Release-сборка принимает только HTTPS.

## Перед выпуском на устройство

Проверьте вход/выход, перезапуск приложения, лобби, загрузку PNG, скачивание PNG/SVG/JSON, закрытие несохранённой карточки кнопкой «Назад», поворот экрана, потерю сети и переключение сервера. JVM-тесты не заменяют эту проверку на Android. Ключи подписи, SDK, `local.properties`, `.gradle` и результаты сборки не входят в исходный архив.

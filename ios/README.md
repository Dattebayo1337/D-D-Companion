# D&D Companion — iPhone и iPad

Нативный проект UIKit / WKWebView для iOS 15+. Откройте `Companion.xcodeproj` на Mac в Xcode. Сторонних Swift-зависимостей нет. Сервер, аккаунты, персонажи, кампании, журнал и казна остаются общими с веб-версией и Android.

**Статус:** исходники и проект подготовлены на Windows. Xcode, симулятор, подпись и установочный IPA здесь недоступны. Сборка Swift и запуск на iPhone не подтверждены. Android APK собирается отдельно.

## Собрать и запустить

1. На Mac установите Xcode с iOS SDK; завершите его первоначальную настройку.
2. Откройте `Companion.xcodeproj`, выберите схему **Companion** и симулятор iPhone/iPad. Run собирает Debug без аккаунта для симулятора. Либо выполните `sh build.sh`: проверки URL-политики через `swift test` и сборка симулятора через `xcodebuild`.
3. Для своего iPhone в **Signing & Capabilities** выберите свою Team и уникальный Bundle Identifier. Текущие ID: `app.dndcompanion.mobile.debug` и `app.dndcompanion.mobile` для Release. Разрешите Xcode создать нужный provisioning profile, выберите подключённое устройство и Run.
4. Для распространения используйте Release → **Product → Archive → Distribute App** и свой аккаунт разработчика/профиль. Не включайте Debug в публичный выпуск. В Assets включена иконка приложения, построенная из существующего SVG проекта. Проект не публикуется автоматически; подпись, App Store Connect и TestFlight требуют вашей настройки.

Установить исходный проект или Android APK на iPhone нельзя. Готовый IPA нельзя корректно выпустить с этого Windows-компьютера без среды Apple и подписи.

## Подключение

Введите HTTPS-адрес размещённого сервера без `/login` и параметров. Приложение проверяет `/api/mobile/status` и не принимает перенаправления проверки. Release допускает только HTTPS; Debug допускает локальные HTTP-адреса для разработки. В симуляторе можно использовать `http://127.0.0.1:3000`, если сервер работает на том же Mac. Адрес 127.0.0.1 на физическом iPhone указывает на сам телефон, не на Windows-компьютер.

Меню содержит обновление, адрес сервера, печать и автономные правила. При смене сервера после подтверждения удаляются вход, браузерные данные и сохранённые правила прежнего подключения. Серверные данные не удаляются. TLS-сертификаты с ошибками не обходятся. Справочники доступны без входа, личные данные — через обычный вход на сервере.

## Файлы, печать и чтение без сети

- Выбор PNG/JSON использует стандартный выбор файлов WKWebView. Экспорт из приложения перехватывается только в главном фрейме выбранного сервера; «Поделиться» позволяет сохранить в «Файлы». Лимит экспорта — 16 МБ. Поддерживаются PNG, SVG, JSON, текст, PDF и ZIP.
- `window.print()` вызывает системное окно печати. Предпросмотр листа, заклинаний и материалов используется тот же, что в веб-версии. PDF доступен через возможности системного диалога печати/поделиться на устройстве.
- «Сохранить для чтения без сети» получает публичную карточку без cookies и передаёт её в приватное хранилище iOS с подтверждением записи. **Для этого нужен актуальный сервер из этого архива.** До 200 карточек и 50 МБ на подключение; обновление — повторным сохранением. Меню → «Читать без сети» работает с локальными снимками, даже если сервер недоступен. Есть редакция, поиск, источник, лицензия и печать. Меню позволяет очистить копии. Они не входят в резервную копию настроек веб-браузера.
- Личные переводы, аккаунты и кампании не сохраняются для автономного редактирования. Сохранённые карточки — снимки, не полная локальная база.

## Проверка на Mac перед использованием

Запустите `sh build.sh`, затем вручную проверьте вход/выход, лобби в двух аккаунтах, черновики и публикацию, загрузку и экспорт файлов, печать, сохранение правил, перезапуск в авиарежиме, отказ при другом origin, смену сервера, поворот iPad и клавиатуру. Эти сценарии на устройстве в текущей Windows-сессии не выполнялись.

Включён privacy manifest с причиной использования UserDefaults для хранения выбранного сервера. Перед публикацией заполните сведения о конфиденциальности и сборе данных в соответствии с вашим хостингом и настройками сервера. Карточка магазина и release-подпись ещё не подготовлены. Готовность проекта не означает одобрение магазина.

Официальные справочники: [WKWebView](https://developer.apple.com/documentation/webkit/wkwebview), [ответы native-моста](https://developer.apple.com/documentation/webkit/wkscriptmessagehandlerwithreply), [печать](https://developer.apple.com/documentation/uikit/uiprintinteractioncontroller), [распространение](https://help.apple.com/xcode/mac/current/en.lproj/devac02c5ab8.html).
